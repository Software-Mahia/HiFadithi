# End-to-end script (owner: A)

Run from the HTTP collection on the deployed server on Saturday:

1. Sign in as a researcher.
2. Create an artefact with height, width and depth.
3. Add a capture with 4 photos.
4. Start a job (fake engine first, then Meshy).
5. Webhook arrives; the version reaches Needs verification.
6. Submit a verification (width, depth, landmark): Pass.
7. Sign in as a curator: approve. The verifier's account is blocked from approving.
8. Search finds the artefact.
